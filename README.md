# 🏫 캠퍼스 생활 설문조사 데이터 분석 웹앱

대학교 학생들의 생활 습관(공부, 수면, 스마트폰 사용)이 학교 생활 만족도에 미치는 영향을 분석하는 파이썬 기반 데이터 시각화 웹 애플리케이션입니다.

## 📊 주요 기능
* **CSV 데이터 업로드 및 전처리**: 결측치(빈 값, '모름' 등) 및 이상치(24시간 초과 데이터) 자동 필터링
* **학과별 맞춤 분석**: 선택한 학과에 따라 모든 그래프와 텍스트 분석 결과가 실시간으로 연동
* **인터랙티브 시각화**: 
  * 만족도 분포 비율 (원그래프)
  * 생활습관 요소 간의 상관관계 (히트맵)
  * 만족도 점수에 따른 습관 변화 추이 (선그래프)
* **텍스트 감성 분석**: 학생들의 '한 줄 의견'에서 자주 등장하는 단어 Top 10을 추출하고, 긍정 및 부정 키워드 등장 빈도를 비교
